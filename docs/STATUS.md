## Deviations from the plan

1. **Gate tool.** Plan: gematik Referenzvalidator with the `diga` plugin. Here:
   HL7 validator 6.5.28, because the only plugin release targets
   1.0.0-festlegung (ADR 0001, user decision 2026-11-02; ADR 0004 for the pin).
2. **Stack.** Plan: `fhir.resources` models and a Typer CLI. Here: plain dicts
   and argparse (ADR 0003). Not yet confirmed by the user against the plan.
3. **PROM wording.** Resolved 2026-11-11: scores and codes only, as the plan
   says (ADR 0007). A unit test guards against item wording.
4. **Golden files.** Plan: written by hand from the profile, validated, then
   matched by the mapper. Here: generated by the mapper and reviewed. The
   independent checks are the validator, the negative control and the
   fhir-reviewer.
5. **Archetype C.** The plan's layout says `archetype_c_tinnitus`, its Phase 2
   and licence section say pain with a 0–10 numeric rating scale. Follow
   Phase 2 (pain).
