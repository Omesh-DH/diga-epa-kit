diga-epa-kit try it

Turn typical DiGA data into a KBV MIO DiGA 1.1.0 FHIR document bundle for the ePA. The kit runs in this browser tab: your data never leaves your computer.

Use synthetic or test data only. This is not a certified medical device and has not been tested against a real ePA.

What this page does not do

It runs the kit's own checks, not the official HL7 FHIR validator, which needs Java and the KBV packages. To validate a bundle against the profiles, install the kit and run diga-epa-kit validate bundle.json --jar validator_cli.jar --ig … (see the quickstart). Known problems in the specification itself are listed in docs/gaps.md.
